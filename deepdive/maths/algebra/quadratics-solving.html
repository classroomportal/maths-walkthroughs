Deep Dive: Quadratics — Part B

Solving quadratic equations — two answers, one answer, no answer, and why

Before You Start

How long will this take?
Most students: around 45–55 minutes.
Still building confidence? Take up to 70 minutes, over more than one sitting if needed — your progress is saved as you go.
Already confident? You might move through it in 25–30 minutes.
Stage 1

x² = 16: Two Solutions

In Part A you learned that every positive number has two square roots. That matters a lot here.

x² = 16
x = ±√16
x = +4 or −4
4² = 16 ✓    (−4)² = 16 ✓

Both values make the equation true — so both are correct solutions. Whenever you square-root to solve, always write ± unless you have a reason not to.

Stage 2

x² = 0: Only One Solution

What happens at the boundary case, when the number being square-rooted is zero?

x² = 0
x = ±√0
x = +0 or −0
+0 and −0 are the same number. The two solutions collapse into just one: x = 0.
This is called a repeated root — it'll come back later when we complete the square.
Stage 3

x² = −4: No Real Solution

Recall from Part A: squaring a positive number gives a positive result, and squaring a negative number also gives a positive result.

No matter what real number you choose for x (positive, negative, or zero), x² can never be negative.
x² = −4 has no real solution — there's no real number you can square to get a negative answer.
Stage 4

Seeing It on a Graph

The graph of y = x² is a curve called a parabola. It never dips below the x-axis, which matches exactly what you found in Stage 3.

Now add all three lines from Stages 1 to 3 onto that same curve, so you can compare them directly.

The line y = 16 crosses the curve at two points: x = −4 and x = 4. Two crossings, two solutions.

The line y = 0 (the x-axis itself) just touches the curve once, at the very bottom. One touch, one repeated solution.

The line y = −4 never touches the curve at all. Zero crossings, zero real solutions, exactly what Stage 3 found algebraically.

Three quick checks below, one for each case on the graph above.

Stage 5

Solving by Factorising

Most quadratics don't come as neatly as x² = k. For x² + 5x + 6 = 0, we factorise instead — using the same skills from the Algebra chain.

x² + 5x + 6 = 0
Factorises to: (x + 2)(x + 3) = 0
Key rule — if two things multiply together to make zero, at least one of them must be zero.
Either (x + 2) = 0  →  x = −2
or (x + 3) = 0  →  x = −3
x = −2 or x = −3
Stage 6

Completing the Square

Factorising doesn't always work nicely. Completing the square gives you a method that always does, and it brings back the ± idea from Stage 1.

Where does "completing the square" actually come from? Picture x² + 6x as an area.

Start with a square with sides of length x. Its area is x².

Split 6x into two strips of width 3, and attach one to the right and one to the bottom. Each strip has area 3 × x = 3x, so together they add 6x. The shape is now an "L" with total area x² + 6x.

There's a gap in the corner: a small square, 3 by 3, area 9. Without it, the shape isn't a proper square yet.

Fill the gap and the whole shape becomes one big square, side (x + 3).
Area = (x + 3)² = x² + 6x + 9
So: x² + 6x = (x + 3)² − 9 (we subtract the 9 we added to balance it back out)

Now use that to solve an equation.

x² + 6x can be rewritten as (x + 3)² − 9, exactly as the diagram showed.
x² + 6x + 5 = 0
(x + 3)² − 9 + 5 = 0
(x + 3)² − 4 = 0
(x + 3)² = 4
x + 3 = ±2  (± again — same idea as Stage 1)
x = −3 + 2 = −1    or    x = −3 − 2 = −5
x = −1 or x = −5

Completing the square doesn't need factors to exist. Try x² + 4x − 1 = 0 — this one won't factorise nicely at all.

x² + 4x can be rewritten as (x + 2)² − 4 (half of 4 is 2, squared is 4)
x² + 4x − 1 = 0
(x + 2)² − 4 − 1 = 0
(x + 2)² = 5
x + 2 = ±√5  (√5 stays as a surd, from the Numbers chain)
x = −2 + √5  or  x = −2 − √5
These are perfectly valid, exact answers — they just aren't whole numbers. A calculator would show √5 ≈ 2.236, but leaving it as √5 is the exact form.
Stage 7

Bringing It All Together

Completing the square doesn't just solve the equation — the form (x + 3)² − 4 also tells you exactly where the graph's lowest point (the vertex) is.

Vertex at (−3, −4), read directly from (x + 3)² − 4.
The curve crosses the x-axis at x = −1 and x = −5, exactly the answers from Stage 6.
The whole story in one sentence: how many times the parabola crosses the x-axis is how many real solutions the equation has: 2 crossings, 1 touch, or 0.
